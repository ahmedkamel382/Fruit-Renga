# Fruit Renga 🍓🎮

Fruit Renga is a fast-paced game developed in C using the SDL library. Click on falling fruits to earn points, but watch out for bombs! Special items add exciting twists to the gameplay.

## Features
- **Fruit Clicking:** Click on falling fruits to earn points.
- **Bombs:** Avoid clicking bombs, or you'll lose points!
- **Golden Apple:** Grants double points when clicked.
- **Heart:** Restores one health point.
- **Health System:** Lose health if a fruit falls without being clicked.

## How to Play
1. Run the game.
2. Click on falling fruits before they disappear.
3. Avoid clicking bombs.
4. Catch special items for extra points and health.
5. Keep your health up and aim for the highest score!

## Requirements
- **C compiler**
- **SDL library** installed

## Installation
1. Clone the repository:
   git clone https://github.com/ahmedkamel382/Fruit-Renga
2. Compile the source code using the SDL library.
3. Run the game executable.
